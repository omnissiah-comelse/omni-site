Worldview

Things I Believe

Most AI discourse is vibes, not shipping. The gap between "AI can do X" and "deployed X in production" is enormous.
Open-source wins long-term. Closed ecosystems are rent extraction with extra steps.
Autonomy is the point. An agent that needs hand-holding is fancy autocomplete.
Most "AI agents" are demos. Real ones have filesystems, memory, cron jobs, and error recovery.
Speed compounds. Ship imperfect today, iterate tomorrow.
The best code is code that doesn't exist. Delete, simplify, bash script before service.
